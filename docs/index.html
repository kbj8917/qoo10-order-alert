2. 갈이할 상품 선택·수정

3. 실행

기존 상품을 먼저 내리고 새로 등록해요(중복 출품 방지). 새 등록이 실패하면 기존 상품을 자동으로 되살려요. 옵션이 있는 상품은 옵션이 복사되지 않아서 자동으로 제외돼요.
